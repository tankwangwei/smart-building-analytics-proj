## What could not be checked

- **Reproduction from the raw 1-minute data (A1, A2 second half):** `combined_by_floor.csv` (618 MB) is not in the repository, so recomputing energy and peaks from raw minutes was not done. Instead the stored KPIs were reconciled against the 15-minute detail (see A2 below).
- **Training-year refit and a true leakage audit of M1 (B1):** the Jul 2018 – Jun 2019 loads are not in the repository either. The audit checks what can be seen: the lag models use only values from >= 24 h / 168 h earlier, and M1 is one fixed profile over the whole test period (it is not refit on test data).
- **Realistic weather (B6):** re-scoring with Open-Meteo's historical-forecast archive needs network access and was not run. The weather models still use observed weather, so their accuracy is optimistic.
- **Eyeball precision/recall (A5):** needs a person. `docs/verification_event_sample.csv` lists 20 random flagged events and 20 random unflagged unit-days (fixed seed) with an empty `judgement` column to fill in.
